entry here in the same pull request.

## Assets

No assets yet. Each asset gets one entry in this table:

| Path | Made by | How | Licence |
| ---- | ------- | --- | ------- |

- **Path:** the file or folder, from the repo root.
- **Made by:** the person or tool that made it.
- **How:** drawn by hand, generated (with the command), or converted from
  another asset (naming it).
- **Licence:** one of the licences above.
